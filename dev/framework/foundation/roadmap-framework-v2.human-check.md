## Statut

**🟣 H001 — INTERVENTION HUMAINE ACTIVE, NON BLOQUANTE POUR LES TRAVAUX INDÉPENDANTS**

## Pourquoi l'humain intervient

1. les choix d'ergonomie du catalogue et du Preset Manager seront réutilisés dans plusieurs Wiz ;
2. les retours réels de manipulation peuvent modifier la primitive avant duplication ;
3. les conventions d'IDs, d'aide, de presets et de feedback doivent être jugées sur l'usage réel, pas seulement sur le code.

## À vérifier maintenant

- [ ] le Preset Manager est compréhensible sans documentation longue ;
- [ ] créer / dupliquer / renommer / supprimer un preset est clair ;
- [ ] modifier puis enregistrer/valider un preset correspond au workflow attendu ;
- [ ] le preset actif est identifiable visuellement ;
- [ ] reset canonique, import et export JSON sont compréhensibles ;
- [ ] les retours visuels après action sont suffisants ;
- [ ] l'ID humain permet de signaler précisément un problème ;
- [ ] la Preview affichée porte bien le numéro de version attendu.

## Décision attendue

- valider la primitive ;
- demander une correction ciblée ;
- déplacer une amélioration non bloquante vers `LATER` / `NOTE` ;
- ne pas élargir automatiquement le périmètre du cycle courant.
